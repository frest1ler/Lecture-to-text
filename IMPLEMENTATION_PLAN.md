# План и критерии готовности

1. Самодостаточный `.ipynb`: ссылка → установка → аудио → Whisper → файлы и поле копирования.
2. Бесплатное выполнение в Colab: GPU при наличии, CPU иначе; без вызовов платного API.
3. Аудио скачивается один раз. Фрагменты по 10 минут с контекстом по 5 секунд;
   слова из перекрытия распределяются по середине их временного интервала.
4. Контрольные точки записываются атомарно после каждого фрагмента. Настройки и
   версии отделяют несовместимые результаты. Частичный текст доступен при сбое.
5. Экспорт: TXT, TXT с таймкодами, SRT, JSON и ZIP, плюс запрос для ChatGPT.
6. Проверки: структура и компиляция ячеек, реальная нарезка ffmpeg, метки времени,
   перекрытие, повреждённые контрольные точки, сбой/продолжение, содержимое архива.
7. Отдельно проверить реальное распознавание короткой речи, если окружение позволяет
   скачать зависимости/модель. Не выдавать имитацию модели за проверку распознавания.

Ограничения, которые нельзя исправить кодом: доступность бесплатной GPU/сеанса,
блокировка YouTube по IP, доступ к весам моделей. Для YouTube предусмотрен ручной
ввод файла. Сохранение между удалениями машины требует опционального доступа к Drive.
