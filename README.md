# Расшифровка YouTube в бесплатном Colab

Основной вариант — **[YouTube_Whisper_Free_Colab.ipynb](YouTube_Whisper_Free_Colab.ipynb)**.
Он самодостаточный: другие файлы этого каталога загружать в Colab не требуется.

1. Скачайте блокнот и откройте его в [Google Colab](https://colab.research.google.com/)
   через «Файл → Загрузить блокнот».
2. Выберите GPU в настройках среды, если доступна.
3. Вставьте ссылку в `VIDEO_URL` и нажмите «Выполнить все».
4. В последней ячейке скопируйте расшифровку или скачайте ZIP с TXT, таймкодами,
   SRT, JSON и готовым запросом для ChatGPT.

API-ключ и оплата API не нужны. Модель работает на машине Colab. Бесплатные GPU
и длительность сеанса не гарантированы. Если YouTube блокирует загрузку по IP,
включите `UPLOAD_LOCAL_FILE` и выберите свой файл. Полностью автоматический
путь по ссылке работает при доступности видео для загрузки из Colab.

По умолчанию прогресс сохраняется на диске текущей машины Colab. Для сохранения
между удалениями машины заранее включите `SAVE_TO_DRIVE` и разрешите подключение
Drive. Повторите запуск с теми же настройками, чтобы использовать готовые части.

Исходный модуль: `colab_transcribe.py`. После его изменения пересоберите блокнот:

```bash
python3 build_notebook.py
python3 -m unittest -v test_colab_transcribe.py
```

План: [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md).
Результаты проверок и их ограничения: [VALIDATION.md](VALIDATION.md).

## Предыдущий вариант: автоматический конспект через платный API

Ниже описан отдельный скрипт `lecture_notes.py`; для Colab-блокнота он не нужен.

Python 3.10+, `ffmpeg` и `ffprobe` должны быть установлены.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
read -rsp 'OpenAI API key: ' OPENAI_API_KEY
export OPENAI_API_KEY
python lecture_notes.py 'https://www.youtube.com/watch?v=kgccc0I_kkw' --model YOUR_TEXT_MODEL
```

Замените `YOUR_TEXT_MODEL` на доступный вашему API-проекту идентификатор
текстовой модели с поддержкой Responses API. Ключ вводится в терминале,
передавать его в чат не нужно. Использование API платное.

Скрипт скачивает аудио один раз, делит его на 10-минутные части с 15 секундами
предыдущего контекста. Три параллельных обработчика распознают речь и составляют
конспекты. Затем редактор объединяет их, для длинных лекций — в несколько уровней.
Это отдельные запросы к модели с разными ролями; модель получает текст после
распознавания, а не смотрит видео.

Результаты в `output/<идентификатор>/`:

- `notes.md` — итоговый конспект;
- `notes-full.md` — подробные конспекты всех частей в порядке лекции;
- `transcript.md` — расшифровка с интервалами фрагментов;
- отдельные аудиофайлы, расшифровки и конспекты — для продолжения после ошибки.

Повтор той же команды использует готовые результаты. Изменение моделей,
языка или нарезки создаёт отдельный каталог. Одновременный запуск двух процессов
с одинаковыми настройками в один каталог не поддерживается.

```bash
# Только загрузка и нарезка: без API-ключа и платных запросов
python lecture_notes.py 'https://www.youtube.com/watch?v=kgccc0I_kkw' --model YOUR_TEXT_MODEL --prepare-only

# Если аудио/видео уже скачано
python lecture_notes.py ./lecture.mp4 --model YOUR_TEXT_MODEL --workers 4
```

Если YouTube отказывает в доступе, обновите `yt-dlp` (`pip install -U yt-dlp`).
При необходимости можно добавить `--cookies-from-browser firefox` для своего
браузера или передать локальный файл. Cookie не сохраняются скриптом в файлы.
Недоступность скачивания не исправляется увеличением числа обработчиков.

Конспект основан на речи: формулы и диаграммы, показанные только на слайдах,
могут быть пропущены. Таймкоды относятся к фрагментам, не к отдельным фразам.
Часть аудио в начале соседних фрагментов повторяется; редактор убирает повторы
в итоговом тексте. Автораспознавание может ошибаться в терминах и формулах.

API: [распознавание речи](https://developers.openai.com/api/reference/python/resources/audio/subresources/transcriptions/methods/create),
[генерация текста](https://developers.openai.com/api/docs/guides/text?lang=python).
